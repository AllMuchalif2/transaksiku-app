## ✨ Deskripsi Singkat

**Transaksiku-App** adalah aplikasi pencatat transaksi yang membantu Anda mengelola dan memantau keuangan pribadi secara mudah. Dengan aplikasi ini, Anda dapat mencatat pemasukan dan pengeluaran, memfilter transaksi, serta mengetahui selisih keuangan setiap saat.

Aplikasi ini dibangun menggunakan **Flutter**, sehingga dapat dijalankan di berbagai platform (Android, iOS, dan lainnya).

---

## 🔥 Fitur Utama

- **Catat & Ubah Transaksi**
  - Tambahkan dan edit data pemasukan atau pengeluaran dengan mudah.
- **Filter Transaksi**
  - Saring data berdasarkan harian, bulanan, tahunan, atau tampilkan semua transaksi.
- **Laporan Selisih**
  - Dapatkan informasi selisih antara total pemasukan dan pengeluaran.
- **Tampilan Sederhana & Intuitif**
  - UI bersih, mudah digunakan untuk semua kalangan.

## 📱 Teknologi

- Dibangun dengan **Flutter** & **Dart**
- Cross-platform (Android, iOS, dst.)

## 🚀 Instalasi

1. **Clone repository:**
   ```sh
   git clone https://github.com/AllMuchalif2/transaksiku-app
   cd transaksiku-app
   ```

2. **Install dependencies:**
   ```sh
   flutter pub get
   ```

3. **Jalankan aplikasi:**
   ```sh
   flutter run
   ```
